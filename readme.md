# 价探 · koishi-plugin-price-watch

一个给自己用的硬件价格监控机器人插件。

起因很朴素：我想换显卡，又不想每天开三个 App 刷价格。于是写了这个，让机器人帮我盯，每天早上把行情做成一张「报纸」发过来。

---

## 现在到底能干什么

不吹，直接说现状：

| | 状态 | 说明 |
|---|---|---|
| 手动记价 | ✅ 能用 | `价格 管理 录入 5070ti 6299` |
| 淘宝自动采集 | ✅ 能用 | 首页 → 搜索 → 点商品卡，走的是真人操作 |
| 日报 / 周报 / 月报 | ✅ 能用 | 三套主题，出图 |
| 性价比榜 / 显卡天梯 | ✅ 能用 | |
| 拼多多、京东 | ⚠️ 走官方 API | 网页端抓不动了，见下面 |
| 外部爬虫推数据 | ✅ 能用 | `POST /price-watch/ingest` |

### 为什么拼多多和京东不做网页抓取

不是偷懒，是实测过：

- **拼多多**：网页上价格是 `大促价¥ 1??99.??`，旁边一行字「前往 APP 查看价格」
- **京东**：搜索页会跳到 `JDR_shields` 验证页，商品页价格也常常打码

这两家我折腾了很久（换 UA、真实鼠标键盘、拦包分析），最后结论是打不过。所以这个插件对它们改用**官方联盟 API**，代码留着，填上密钥就能用。没有密钥也不影响——手动录入照样出报表。

## 装一下

```bash
npm i koishi-plugin-price-watch
```

或者在 Koishi 控制台插件市场搜 `price-watch`。

装完之后最省事的做法是**先看效果**：

```text
价格 管理 演示     # 灌一份假数据
价格 日报 -i        # 出图看看
```

假数据只是为了出图，不会混进真实采集。

## 怎么用

### 一、手动记价（最实在）

```text
价格 管理 录入 5070ti 6299
价格 管理 录入 990pro 1099
```

型号库里没有的型号会自动建。这就是我平时用得最多的方式——每周花两分钟记一下，比什么都准。

### 二、淘宝自动采集

```yaml
collect:
  browserEnabled: true
```

```text
价格 管理 登录 淘宝    # 扫码，扫完别关窗口
价格 管理 采集 -p 淘宝
```

它自己会：搜索型号 → 点进商品卡 → 从 URL 提取商品 ID → 读价格 → 自动建好报价记录。
下一轮就直接采了。

### 三、拼多多 / 京东走 API

```yaml
api:
  pdd:
    clientId: xxx
    clientSecret: xxx
  jd:
    appKey: xxx
    appSecret: xxx
```

申请地址：[多多进宝开放平台](https://open.pinduoduo.com) · [京东联盟开放平台](https://union.jd.com/openplatform/api)

配好后 `价格 管理 数据源` 能看到每个平台当前走哪条路。

### 四、你有自己的爬虫？直接推给我

```bash
curl -X POST http://127.0.0.1:5140/price-watch/ingest \
  -H 'Content-Type: application/json' \
  -d '{"token":"xxx","quotes":[
        {"platform":"jd","model":"RTX 5070 Ti","price":6299,"shopName":"京东自营"}]}'
```

格式就三个必填：`platform`、`model`、`price`（单位是**元**）。其余可选。
插件会帮你做清洗：价格不合理、偏离历史太多、字段乱填的，都会被拒并告原因。

## 报表长什么样

三套主题，宽度固定 960，高度随内容长，为手机看设计：

| 主题 | 感觉 |
|---|---|
| `newspaper` | 报纸：报头、期号、双栏、衬线体 |
| `marble` | 大理石：希腊柱式、罗马数字、金色描边 |
| `pixel` | 像素：ASCII 边框、深色底、等宽字 |

```text
价格 日报 --theme 大理石
价格 周报 -i
价格 月报 京东
```

## 价格靠不靠谱

采到的价要过三道闸门，过不了不进报表：

1. **合理性**——0 元、天文数字、12 位以上，直接扔
2. **偏离中位数**——和近 30 天中位数差超过 60%，标成可疑
3. **型号一致性**——标题里得有目标型号；`5070 Ti` 和 `5070` 我当两个东西

还有一层：商家爱用「5070 的标题挂 2060 的 SKU」引流，所以同一个商品里如果有多个型号，要切到目标型号再读价（`collect.switchSku`，默认关，需要时打开）。

## 几个我踩过的坑

**扫完码别关窗口。** 关了不会丢登录态（cookie 在 profile 里），但会重新开一个浏览器实例，指纹变了，平台容易重新要验证。

**服务器中文变方块。** 缺字体，装 `fonts-noto-cjk`。`价格 管理 自检` 会提前告警。

**拼多多取到 ¥1。** 大概率是抓到了「¥1 件」这类噪声，插件会拦下并报「价格异常」，不会写进库。

**出问题了。** 发 `价格 管理 调试`，把 `data/price-watch/debug/debug-*.txt` 发出来。里面有环境、指纹、脱敏配置和最近 400 条日志。
