# 价探 · koishi-plugin-price-watch

> 硬件价格监控机器人插件：盯显卡、内存条、固态硬盘的价格，出报纸风格的日报 / 周报 / 月报。

- **插件标识**：`koishi-plugin-price-watch`（Koishi 内部名 `price-watch`，改名会破坏已加载的配置，见文末）
- **推荐仓库名**：`koishi-price-watch`
- **推荐中文名**：价探

---

## 它做什么

| 能力 | 说明 |
|---|---|
| 查价 | `价格 5070ti` 看某个型号现在多少钱 |
| 报表 | `价格 日报` / `周报` / `月报`，三套主题出图 |
| 榜单 | 性价比榜（每百元性能 / 每 GB 价格）、显卡天梯图 |
| 监控 | 关注型号、涨跌提醒、定时推送 |
| 采集 | 淘宝走仿真搜索；拼多多/京东走官方 API |
| 录入 | 没有密钥也能手动记价，报表照常出 |

## 为什么是这么设计的

三家平台的数据获取难度完全不同，这是实测结论：

| 平台 | 网页端现状 | 本插件方案 |
|---|---|---|
| 淘宝 | 可抓（首页 → 搜索 → 点商品卡能过风控） | 浏览器仿真 |
| 拼多多 | 价格打码：「大促价 ¥1??99.?? 前往 APP 查看价格」 | 多多进宝 API |
| 京东 | 搜索有 `JDR_shields` 验证墙，商品页价格也常打码 | 京东联盟 API |

所以插件只保留**一条网页采集链路（淘宝）**，其余走官方接口；两条都不可用时，**手动录入**兜底，报表功能完全不受影响。

## 快速开始

### 1. 安装

```bash
# 在 Koishi 项目里
npm i koishi-plugin-price-watch
```

或在 Koishi 控制台「插件市场」搜索 `price-watch` 安装。

### 2. 最小可用配置

```yaml
price-watch:
  basic:
    mode: image        # text | image | markdown
    theme: newspaper   # newspaper | marble | pixel
```

装上就能用：型号库自动导入 28 个常见型号。

### 3. 先灌一份演示数据看看效果

```text
价格 管理 演示
价格 日报 -i
```

演示数据只用于出图，不参与真实采集。

### 4. 真实数据

**方式 A：手动录入（推荐先这样用）**

```text
价格 管理 录入 5070ti 6299
价格 管理 录入 990pro 1099
价格 日报
```

**方式 B：淘宝自动采集**

```yaml
collect:
  browserEnabled: true
  browserHeadless: true
```

```text
价格 管理 登录 淘宝     # 扫码，成功后窗口保留
价格 管理 采集 -p 淘宝
```

**方式 C：拼多多 / 京东官方 API**

```yaml
api:
  pdd:
    clientId: 你的 clientId
    clientSecret: 你的 clientSecret
  jd:
    appKey: 你的 appKey
    appSecret: 你的 appSecret
```

申请入口：[多多进宝开放平台](https://open.pinduoduo.com) · [京东联盟开放平台](https://union.jd.com/openplatform/api)

配好后 `价格 管理 数据源` 能看到每个平台当前走哪条路。

```text
价格 天梯                显卡性能天梯图
价格 帮助                完整速查表
```

### 订阅

```text
价格 关注 加 990pro
价格 关注 列表
价格 关注 删 990pro
```

### 管理（仅主人）

```text
价格 管理 我是谁          查看自己的平台:用户ID
```

## 三套主题

| 主题 | 风格 |
|---|---|
| `newspaper` | 报纸：报头、期号、双栏、衬线字体 |
| `marble` | 大理石：希腊柱式、罗马数字、金色描边 |
| `pixel` | 像素：ASCII 边框、深色底、等宽字体 |

宽度固定（默认 960px），高度按内容自适应，适合手机纵向阅读。

## 数据质量

采集到的价格要过三道闸门，不合格的不进报表：

| 闸门 | 规则 |
|---|---|
| 合理性 | 0 元、天文数字、12 位以上一律拦 |
| 偏离中位数 | 与近 30 天中位数偏离超 60% 标可疑 |
| 型号一致性 | 标题代号必须含目标型号（Ti 与非 Ti 是两个型号） |

`价格 管理 自检` 会输出：

```text
数据质量：成功 61 · 缺货 1 · 可疑 0（共 62 条）
  · taobao 最近失败：缺货
```

## 常见问题

**Q：为什么拼多多/京东不能像淘宝那样直接抓？**
A：拼多多网页端价格已打码（页面写「前往 APP 查看价格」），京东搜索有 `JDR_shields` 验证墙。这不是代码问题，是平台策略。插件对这两家改用官方 API。

**Q：没有 API 密钥怎么办？**
A：用 `价格 管理 录入`。报表、榜单、天梯图全部可用，数据来源不影响出图。

**Q：登录窗口可以关吗？**
A：淘宝登录成功后**别关**，采集会复用它（`collect.keepLoginWindow: true`）。关了也不会丢登录态（cookie 在 profile 里），只是会重新开一个浏览器实例。

**Q：图片里中文变成方块？**
A：服务器缺中文字体，安装 `fonts-noto-cjk`。`价格 管理 自检` 会提前告警。

**Q：出问题怎么反馈？**
A：发 `价格 管理 调试`，把生成的 `data/price-watch/debug/debug-*.txt` 发出来。里面有环境、浏览器指纹、脱敏配置和最近日志。

## 关于改名

插件在 Koishi 里的标识是 `price-watch`（`koishi.yml` 里的 `price-watch:xxxx` 也是它）。**改名会导致已加载的插件配置失效**，所以：

- 对外展示可以叫「价探」
- npm 包名与 Koishi 标识暂时保持 `koishi-plugin-price-watch`
- 真要改名，需要同时改 `package.json` 的 `name`、`koishi.yml` 的插件键，并重新配置一次

## 八、外部爬虫接入（用户自己抓的数据）

> 不想用内置采集？把你自己的爬虫结果推过来就行，插件负责清洗和出报表。

### 8.1 两种接入方式

**方式 A：HTTP（推荐给脚本/服务）**

```bash
curl -X POST http://127.0.0.1:5140/price-watch/ingest \
  -H 'Content-Type: application/json' \
  -d '{
    "token": "你在配置里设的 token",
    "source": "my-crawler",
    "quotes": [
      { "platform": "jd", "model": "RTX 5070 Ti", "price": 6299,
        "itemId": "100012043978", "shopName": "京东自营",
        "title": "华硕 RTX 5070 Ti 16G", "listPrice": 6599 }
    ]
  }'
```

返回：

```json
{ "ok": true, "accepted": 1, "rejected": [], "day": 20261101 }
```

**方式 B：聊天里直接导入（仅主人）**

```text
价格 管理 导入 {"quotes":[{"platform":"jd","model":"RTX 5070 Ti","price":6299}]}
```

### 8.2 数据格式

| 字段 | 必填 | 说明 |
|---|---|---|
| `platform` | ✅ | `jd` / `pdd` / `taobao` / `manual` |
| `model` | ✅ | 型号名，如 `RTX 5070 Ti`。库里没有会自动新建 |
| `price` | ✅ | **元**（不是分），需在合理区间内 |
| `itemId` | 否 | 商品 ID，用于绑定与去重 |
| `title` | 否 | 商品标题，用于型号校验 |
| `shopName` | 否 | 店铺名 |
| `url` | 否 | 商品链接 |
| `listPrice` | 否 | 原价/列表价 |
| `day` | 否 | 数据日期 `YYYYMMDD`，默认今天 |
| `note` | 否 | 备注 |

### 8.3 插件会做什么清洗

| 规则 | 行为 |
|---|---|
| 平台不认识 | 拒绝，返回原因 |
| 型号名为空 | 拒绝 |
| 价格不在合理区间（<100 或 >20 万） | 拒绝 |
| 价格偏离近 30 天中位数 >60% | 拒绝（标可疑，不进正常价） |
| 型号库里没有 | **自动新建型号** |
| 通过后 | 写快照 → 重建日聚合与统计 → 报表立刻可用 |

### 8.4 安全

- 配置 `ingest.token` 后，HTTP 请求必须带同值 `token`，否则 `401`
- 不设 token 时 HTTP 接口仍开放（仅限内网），聊天里的「导入」指令则始终要求主人身份
- 完全不想开：`ingest.enabled: false`

### 8.5 幂等

同一天、同一平台、同一型号多次推送，**以最后一次为准**（写的是当天快照），不会产生重复行。
